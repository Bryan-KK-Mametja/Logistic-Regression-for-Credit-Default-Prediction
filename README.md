# Logistic-Regression-for-Credit-Default-Prediction
An end-to-end data science repository evaluating the impact of class imbalance on logistic regression for credit default prediction. Implements four pipelines—Standard Baseline, SMOTE, Random Undersampling, and Random Oversampling—using the UCI credit dataset. Evaluated via Accuracy, F1-Score, and ROC-AUC to analyze default risk.
